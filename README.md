# Connect Four Web

A simple, local two-player Connect Four game built with React.

## Requirements

- Node.js (tested on Node 22)
- npm

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server (hot reload):

```bash
npm run dev
```

This starts the CRA dev server, by default at http://localhost:3000.

## Production build

Build a static production bundle:

```bash
npm run build
```

Serve the built output:

```bash
npm start
```

This serves the `build/` folder at http://localhost:3000.

## Scripts

| Script         | Description                                  |
| -------------- | --------------------------------------------- |
| `npm run dev`  | Start the CRA dev server with hot reload       |
| `npm run build`| Create an optimized production build           |
| `npm start`    | Serve the production build with `serve`        |
| `npm test`     | Run tests                                       |

## Tech stack

- React 16
- Create React App (`react-scripts` 3.4.3)
